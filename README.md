# data-project_phyton_katas
Data Project: Lógica. Katas Python

¿ Qué es una Kata?
En programación, una kata es un ejercicio práctico diseñado para mejorar las habilidades de un programador mediante la repetición y el perfeccionamiento de técnicas de codificación.

¿Cómo funciona una Kata?
Generalmente, una kata presenta un problema o desafío de programación que el programador debe resolver.


Las katas pueden hacerse de distintas maneras para obtener el mismo resultado. A lo largo del proyecto debes demostrar los siguientes conocimientos:
● Manejo de tipos de datos básicos y funciones incorporadas.
● Manejo de estructuras de datos en Python y sus métodos.
● Manejo de condicionales.
● Manejo de estructuras de iteración
● Manejo de funciones en Python.
● Manejo de Clases y entendimiento de la programación orientada a objetos.
● Uso de módulos.
● Buenas prácticas.


El proyecto consta de dos archivos:
1. Archivo README.md, que recoje los pasos seguidos durante el proyecto.
2. Archivo phytonKatas.py con los ejercicios resueltos. Cada ejercicio tiene que ir acompañado del enunciado y comentarios explicando el enfoque de la resolucion

Crear carpeta y dentro el .py
Para el uso de Python desde Visual Studio Code (VSCode) instalé estas extensiones:
Python: Para ejecutar código Python dentro del editor.
Jupyter Notebook: Para trabajar con archivos .ipynb interactivos, que permiten ejecutar celdas de código de forma secuencial y ver los resultados inmediatamente.
autoDocstring - Python Docstring Generator. Una extension que te genera automáticamente un bloque de documentación para documentar el código (funcionamiento, los parámetros y el return, si lo tiene).
*docstring es un texto de documentación que va dentro de la función, justo después de def, y explica:
•	Qué hace la función
•	Qué parámetros recibe
•	Qué devuelve
